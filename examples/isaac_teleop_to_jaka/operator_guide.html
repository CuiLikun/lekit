CONNECT没反应？确认头显和工作站同一网络，核对终端IP和48322证书地址。保持 Device Profile=Custom · Panel=Center · Headless关闭。
手柄/键盘控制
输入动作面板反馈
A / a / n / →开始或结束当前回合READY / RECORDING
B短按 / Space暂停或恢复当前回合PAUSE / RECORDING
B长按 / b执行 reset_joints 复位RESETTING
squeeze按住接合TCP控制，松开保持目标ENGAGED / HOLD
trigger每次按下切换夹爪目标gripper toggle
摇杆上下=pitch · 左右=yaw · 按住+左右=rollLOCK_POSE基准
r / ←放弃当前回合，回到等待READY
Esc / q停止采集，释放硬件安全停止
READY
还没有写入。确认站位和方向，按A开始。
RECORDING
正在写数据。A结束回合，B/Space暂停。
PAUSE
回合保留，不写帧。再按B/Space继续。
RESETTING
B长按触发，Servo关闭后执行复位。
STOP
Esc/q停止并释放硬件。
JAKA base frame 坐标方向
+X机器人右侧 / TCP向右
+Y机器人前方 / TCP向前
+Z向上 / TCP上升
站位：操作者在机器人侧后方，与机器人同向（面向+Y）。
head yaw：每次squeeze接合只锁存一次头显水平yaw，接合后转头不会让TCP漂移。
验证：首次接合只做三笔小动作，看TCP是否跟手柄同向；方向不对立刻松开squeeze。
Rerun 检查清单
✓Episode号与当前回合一致，帧序从0增长
✓暂停显示PAUSE，恢复后RECORDING，暂停区间不写入
✓相机画面连续，Episode标签居中显示
✓joint_1.pos ~ joint_6.pos 曲线无明显断裂
✓gripper.pos 在每次trigger后保持正确目标值
✓LOOP接近30Hz，CAM TIMEOUT未持续增加
!
异常先停。方向反了/TCP漂移/夹爪跳变/CAM TIMEOUT持续增加→松开squeeze，按Esc/q。记下现象和面板状态，处理完再继续。
收尾
A 结束回合
面板回READY，保存episode
B长按 复位
等RESETTING→READY再继续
Esc/q 退出
释放XR和硬件，刷新Rerun
